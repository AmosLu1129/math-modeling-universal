# 出版级图面设计：先定论证契约，再画

每张论文图是一个**视觉论证**，不是孤立的漂亮图。动笔前先写契约：核心结论、证据链、图面原型、面板规划、审稿风险。图服务于科学逻辑；美观排在论证清晰之后。

## 必填契约（画图前在笔记或回复中写清）

```text
核心结论：一句话（带动词）——"方案 A 通过降低 X 使误差减少 32%"，而不是"方案比较"
图面原型：quantitative grid / schematic-led composite / asymmetric mixed-modality
最终尺寸：单栏约 3.5in / 双栏约 7.2in（直接按最终尺寸出图）
面板规划：
  a: 主证据（hero）
  b: 支持证据
  c: 稳健性/对照
证据层级：主证据 / 验证证据 / 对照与稳健性
统计需要：误差类型（SD/SEM/95%CI）、n、检验方法
数据来源：results.json 哪个字段
审稿风险：样本量可见吗？误差与检验定义了吗？可比面板的轴可比吗？能否用更少面板说清？
```

## 四种图面原型（archetype）

| 原型 | 何时用 | 主面板 | 支持面板 |
|---|---|---|---|
| `quantitative grid` | 论据主要是数值比较 | 可无，常给一个主导汇总指标 | 共享轴、对齐刻度、紧凑图例 |
| `schematic-led composite` | 需先看懂流程/机理/系统结构（模型结构图、算法流程图、机理图） | 左侧或顶部示意图，占 35-60% 面积 | 2-4 个定量验证面板 |
| `image plate + quant` | 影像/地图/空间分布领衔 | 代表图或影像板 | 比例尺、叠加、量化 |
| `asymmetric mixed-modality` | 示意图 + 影像 + 热力图 + 定量图混排 | 一个面板跨行/跨列 | 按证据价值排序的小面板 |

## 面板逻辑（默认顺序，故事需要可调整）

1. 建立系统：数据、方法、实验设计、场景。
2. 主效应或核心比较。
3. 机理/定位/结构。
4. 对代表性结果做量化。
5. 稳健性、对照、子组、灵敏度。

图 1 或方法图的第一面板常定义整张图的视觉语言：颜色、符号、流程方向、类别、比例尺，后面所有面板复用同一套。

## Hero 面板与不对称布局

- 主证据放一个**主面板**，其余面板更小更安静；不要所有面板等大。
- 机理/结构示意做 hero 时：`GridSpec` 用 `height_ratios=[2.2, 1.0]` 或 `[2,1]` 之类，示意图占 45-60% 总高度，定量面板放下面一行；或左示意右定量。
- 支持面板比 hero 更简洁、更少饱和色，让读者按设计顺序读图。
- 同一图内保持同一种方法/条件颜色；示意图颜色与定量图颜色同族，整图像一个整体论证，不是拼贴。

## 可编辑文字（硬性）

```python
plt.rcParams["font.family"] = "sans-serif"
plt.rcParams["font.sans-serif"] = ["PingFang SC", "Hiragino Sans GB", "Arial", "DejaVu Sans"]
plt.rcParams["svg.fonttype"] = "none"   # SVG 文字保持 <text> 节点，可编辑可搜索
plt.rcParams["pdf.fonttype"] = 42       # PDF 内嵌 TrueType 可编辑文字
```

- 默认导出 `.svg`（主）+ `.png`（≥300 DPI）或 `.pdf`；纯 PNG 只有确实不需要改字时才允许。
- 中文论文统一走 `plot_style.py` 的中文字体探测与负号修复，不要手动指定冲突字体。

## 配色策略

- 一张图一个**中性族** + 一个**信号族** + 一个**强调族**；绿/红主要留给"上升/下降、增益/损失"等方向性提示。
- 方法对比多且需整体统一时，用低饱和 pastel 族（同族深浅变化），避免每个方法一个高饱和色。
- 保持色盲安全 + 灰度可分（已有规范照旧）。

## 审稿风险清单（定稿前过一遍）

- 样本量 n 在图注/图内可见？误差棒与统计检验的定义写了吗？
- 引导读者对比的面板，坐标轴范围可比吗？
- 每个面板都承载了不可替代的证据吗？盖住某个面板论点不变 → 删/合并。
- 图的结论在 caption 里能一句话说清吗？caption 是论证的一部分，不是文件描述。

## 与本技能既有规范的衔接

- 选图决策（画什么图）照旧走 `chart-guide.md`；本文件决定**怎么组织图面**。
- 机理示意图的 SVG 绘制规范不变；本文件补充的是"示意图做主面板时版面怎么分、支持面板怎么放"。
- 自检闭环（渲染预览 → 程序自检 → AI 读图复核 → 回改）每张图照旧必过。
