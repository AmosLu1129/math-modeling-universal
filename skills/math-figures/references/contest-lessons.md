# 图表实测教训与获奖范式（按需查阅）

## 一、获奖论文图表标配（2025 国赛 C023/A196/B157 总结）
1. **问题分析逻辑流程图（必备）**：色块区分模块（输入→预处理→建模→结果），箭头串联各问，放在问题分析或引言。
2. **机理/物理示意图（机理题必备）**：展示“这题物理/系统上发生了什么”（几何角度、光路、传输拓扑）。
3. **实景/背景图（可选加分）**：问题重述直观呈现应用场景。
4. **参数论证表（必有）**：任何离散化点数、阈值、超参数均配误差或敏感性表。
5. **算法流程图/伪代码框**：两阶段或搜索算法步骤化呈现。
6. **验证类图表组**：拟合残差图、残差直方图+Q-Q 图、参数相关热力图、敏感性柱/折线图、合成数据校准对比图。
7. **数据分布类图型**：小提琴图、箱线+散点、热力图、三维调优曲面。

## 二、历次压测教训（避坑指南）
- **中文混排拉丁变音符号（如 `模型预测 ŷ`）**：会触发 matplotlib 字体回退，导致相邻中文变方块。轴标签尽量纯中文，特殊符号移至标题/图注或显式指定字体。
- **逐模块数字核对**：聚合结论图画前先打印每条柱/点数值并与 `results.json` 比对，避免关键词误匹配混入错误负相关项。
- **节点多时网络图不标图上节点名**：≥20 个节点全标名必重叠，改为颜色=类别、大小=量级、名称进图注。
- **旋转 45° 的 x 轴标签与负值柱标注冲突**：负值柱用 `va="top"` 下移到柱底更远处，正值用 `va="bottom"`；局部放大读图复核。
- **双轴 + 数据点标注拥挤**：期刊风格下宁可拆成两个子图分别标值；计数/权重类轴也要补单位（个/次）。
- **图底「注：」行禁 mathtext 下标**：写 `Z1` 不写 `$Z_1$`，mathtext 缺字走 logging 不被 warnings 捕获，会静默出豆腐块。
- **对数轴明文刻度**：用明文字符串 + `minorticks_off()`，避免默认对数刻度渲染出 `10^-1` 豆腐块。
- **AI 生成交通/网格基底图防编号**：提示词中重复强调「禁止任何数字编号/序号/计数圆点，区块必须纯色」。
- **PPT 截图替代方案**：若在 Windows/macOS 使用 python-pptx 生成硬角框图并供手动微调，可用 LibreOffice/PowerPoint 导出 PDF 后由 `pdftoppm` 渲染成 PNG 再过 `svg_audit.py` 或视觉复核。
