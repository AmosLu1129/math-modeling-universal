# 科研图表避坑清单

每条都是「错误 → 为什么错（审稿人视角）→ 正确做法」。用户提出会踩坑的需求时，**先说明问题、给替代方案，再动手；用户坚持也照做，但留下劝阻记录**。

## P1 裸均值柱状图
- 错：每组一根均值柱 + 小误差棒，无原始点。n=3 和 n=300 画得一样高。
- 对：n≥10 箱线/小提琴 + 叠加散点；n<10 直接散点/stripplot；非用柱状不可则叠加散点 + 交代误差类型。

## P2 双 Y 轴
- 错：左右两个 y 轴画不同量纲变量，"重合/分歧"是作图者捏造的。
- 对：量纲同则共轴；看相关用散点；看趋势拆上下子图共享 x，或标准化到 [0,1] 后共轴。

## P3 饼图与 3D 图
- 错：饼图（人眼判角度比长度差 3 倍）、3D 柱/3D 饼/3D 表面（视角扭曲数值）。
- 对：占比用横向柱状（按值排序）；3D 数据用热力图 + colorbar 或 contour。

## P4 Y 轴不当截断
- 错：y 轴不从 0 起，小差异看起来像翻倍。
- 对：比例/概率/准确率从 0 起（或合理基线）；跨数量级用 log 轴；必须截断时画断裂标记并在图注说明。

## P5 连续色阶无 colorbar
- 错：颜色深浅映射连续值却不给 colorbar。
- 对：必加 colorbar，带变量名与单位。

## P6 把离散点连成折线
- 错：x 是分类却用折线连均值，暗示不存在的连续趋势。
- 对：分类 → 散点/点图/柱状；只有时间/迭代/剂量等有序连续才用折线。

## P7 过度使用颜色
- 错：颜色当唯一编码通道，类别多时无法区分。
- 对：类别 ≤5 用颜色；更多时加线型/marker 冗余编码或拆图。

## P8 图例缺失或不清
- 错：多条曲线/多组数据无图例，或图例悬空不指代。
- 对：图例清晰、位置不压数据（图外或空白处）；类别 >5 考虑曲线末端直接标注。

## P9 误差类型不交代
- 错：有误差棒/阴影/箱线，却不写是 SD/SEM/95%CI、不写 n。
- 对：图注必写误差类型 + n + 检验方法与校正。

## P10 过度装饰（chartjunk）
- 错：网格全开、渐变背景、阴影立体、无关标注。
- 对：数据墨水比优先；网格只留主刻度浅色线；不装饰。

## P11 分辨率/格式不达标
- 错：位图 <300 DPI；用 JPEG；出图后二次缩放。
- 对：矢量优先（PDF/SVG）；位图 ≥300 DPI；figsize 直接设最终尺寸。

## P12 一图多论点
- 错：一张图塞"更快+更准+更稳"。
- 对：一张图一个核心结论；多论点拆图或进附录。

## P13 红绿对比、不做色盲检查
- 错：红绿区分类别（约 8% 男性色盲）；不出灰度预览。
- 对：色盲友好配色 + 冗余编码；导出灰度预览核对可分性。

## P14 rainbow / jet 色图
- 错：感知不均匀，造假峰。
- 对：viridis / magma / inferno / cividis；双向数据 RdBu_r + center=0。

## P15 显著性符号滥用
- 错：满图 `*` 号，不写检验方法、校正与符号定义。
- 对：只标与论点有关的少数对比；图注写检验 + 校正 + 符号定义；n 小慎标"显著"。

## P16 缺字乱码（中文/负号/特殊符号）
- 错：中文变方框、负号变方框、`± × μ Δ` 上下标缺字。matplotlib 缺字只发 warning 照样出图，导出才发现。
- 对：先配中文字体（plot_style.py 自动探测）+ `axes.unicode_minus=False`；出图前跑 `figure_qa.audit_figure`，缺字直接判 FAIL。

## P17 文字裁切与图例遮盖
- 错：标题/轴标签被画布切掉；图例压住数据点；旋转的长刻度标签出界。
- 对：constrained_layout 或 bbox_inches='tight'；图例移图外 `bbox_to_anchor=(1.02,1)`；长标签旋转 30°+ha='right'；渲染预览读图确认。

## P18 多面板子图编号不对齐
- 错：a/b/c/d 用各子图自身坐标手摆，横竖不成线；`a` 和 `(a)` 混用。
- 对：统一在 axes 比例坐标 (0,1) 左上角 + 相同 points 偏移，同一行等高、同一列左缘对齐；全图编号风格一致（a/b/c 或 (a)(b)(c)）。

## 拦截话术（示例）

> 你要的"3 组各 5 个样本的均值柱状图"会触发 P1：n=5 太小，柱状会让评委怀疑你藏了分布。建议改成**箱线/散点直接显示每个点**，5 个点一览无余，反而更可信。要按原方案画吗？
