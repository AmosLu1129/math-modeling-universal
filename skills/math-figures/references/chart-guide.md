# 选图决策框架

每次画图**先决定画什么、论证什么，再决定怎么画**。这是「图表制作」的起点。

## 决策三轴

### 轴 1：变量结构

| 组合 | 看什么 |
|---|---|
| 1×连续 | 分布 |
| 1×分类 | 占比 |
| 1×分类 + 1×连续 | 组间比较 |
| 2×连续 | 关系 |
| 1×时间/迭代 + 1×连续 | 趋势 |
| 多个连续 | 相关 |
| 二维矩阵（n×m 数值） | 模式 |

### 轴 2：论证意图（最容易被忽略）

同样数据，论点不同图就不同：

- **比较** — "A 比 B 好/差" → 箱线（或带误差柱）+ 散点
- **关系** — "X 越大 Y 越大" → 散点 + 回归 + r 值
- **趋势** — "随时间/迭代/扰动变化" → 折线 + 误差带
- **分布** — "这组数据长什么样" → 直方图/KDE/箱线
- **构成** — "总和分成几份" → 横向柱状（不要饼图）
- **相关** — "哪些变量相关" → 相关性热力图 + colorbar
- **不确定性** — "估计有多准" → 误差棒/置信带
- **差异显著** — "组间差异是否显著" → 箱线 + 显著性标注

### 轴 3：样本量

| 每组 n | 建议 |
|---|---|
| n ≥ 30 | 箱线/小提琴/带误差柱均可 |
| 10 ≤ n < 30 | 优先箱线/小提琴；柱状必须叠加原始点 |
| 3 ≤ n < 10 | 直接散点/stripplot；箱线慎用 |
| n < 3 | 不画箱线/小提琴，直接列点 |
| 总点数 > 10⁴ | 散点加透明度，或 hexbin / 2D KDE |

## 建模论文常见图型速查

| 想表达 | 首选 | 该避免 |
|---|---|---|
| 组间比较（n≥10/组） | 箱线/小提琴 + 散点叠加 | 裸均值柱 |
| 组间比较（n<10/组） | 直接散点/stripplot | 均值柱、箱线 |
| 两变量关系 | 散点 + 回归 + r 值 | 折线（除非 x 有序） |
| 时间/迭代趋势 | 折线 + 误差带 | 柱状 |
| 分布 | 直方图/KDE/箱线 | 饼图 |
| 占比构成 | 横向柱状（按值排序） | 饼图、3D 饼 |
| 多变量相关（3-20 列） | 相关性热力图（RdBu_r + center=0 + annot） | 平行坐标 |
| 矩阵数据 | 热力图（viridis/magma，配 colorbar） | 3D 表面 |
| 拟合效果（真实 vs 预测） | 散点 + 对角线 y=x（可分点/误差着色） | 只看 R² 文字 |
| 残差/误差分布 | 残差直方图/KDE、Q-Q 图、逐点误差折线 | 均值柱 |
| 收敛性 | 损失/误差随迭代折线（对数轴视情况） | 只给最终值 |
| 灵敏度分析 | 折线/误差带（x=扰动幅度，多条线=参数） | 堆一列柱状 |
| 模型对比 | 分组条形（带误差）+ 数值标注 | 只列一个表 |
| 分类性能 | ROC/PR 曲线、混淆矩阵热力图 | 只给准确率 |
| 空间分布 | 地图散点/热力 | 表格堆坐标 |

## 同一批数据，不同论点 → 不同图

例：某模型在 3 个数据集 × 2 个参数设置下的误差。

| 论点 | 图 |
|---|---|
| "参数 A 整体更稳" | 箱线（x=设置，y=误差，合并数据集） |
| "数据集 2 上两设置分歧最大" | 折线（x=数据集，y=误差均值，hue=设置 + 误差带） |
| "误差随数据规模增长" | 散点（x=规模，y=误差，颜色=设置）+ 回归 |
| "哪个设置每个样本都更好" | 逐点配对连线（每样本两点一线） |

## 何时拆图

满足任何一条就拆：

1. 维度组合数 > 12（例 4×4 面板）
2. x 轴分类 > 8 个且标签需旋转 45°+
3. 图例 > 6 项
4. y 轴跨多个数量级且不能用 log
5. 一张图想讲两件事（如"更快"+"更准"）

拆法：按分组维度拆、按 panel 拆、按论点拆、主图 + 附录。

## 图型语义边界

- **折线 vs 散点**：点之间必须有连续关系（时间/迭代/剂量）才用折线；分类点连折线会暗示不存在的趋势。
- **柱状 vs 箱线**：n 小或分布未知时默认箱线 > 均值柱；用柱状必须叠加原始点 + 交代误差。
- **热力图 vs 散点矩阵**：>8 变量用热力图；2-8 个用散点矩阵看分布更丰富。

## 三类图体系与图型多样性（2026-08-15 调研收编）

### 三类图体系（每道题按论证阶段组织）

| 类别 | 选图重点 | 注意事项 |
|---|---|---|
| ① 原始数据（数据理解） | 看分布、看异常、看相关 | 箱线/小提琴/直方图/散点矩阵优先；**至少覆盖"分布 + 关系/异常"两种视角** |
| ② 中间过程（模型/算法） | 看收敛、看对比、看残差 | 收敛折线/分组柱状/QQ 图/残差图；**至少覆盖"收敛/对比 + 误差分析"两种视角** |
| ③ 最终结果（结论支撑） | 支撑结论、对比方法 | 按论点选图（不是按数据形态）；**至少覆盖"对比 + 综合评价"两种视角** |

### 图型多样性硬规则

- **同题全图覆盖 ≥3 种不同图型**（折线/柱状/散点/分布/热力/高级类各算一类）；全是柱状或全是折线 = 视觉疲劳 + 论证单薄，不合格。
- **反冗余**：每个面板只回答一个唯一问题；不得用不同图型重复展示同一数据（审稿人最常见批评）。
- 每类图体系内部也需 ≥2 种视角（如原始数据类至少 1 张分布图 + 1 张关系/异常图）。
- 推荐组合（9 图模板）：①原始数据 ×3 = 直方/KDE + 箱线 + 散点矩阵；②中间过程 ×3 = 收敛折线 + 分组柱状 + QQ/残差；③最终结果 ×3 = 对比柱状 + 预测-真实散点 + 雷达（多指标）。
- 算"不同图型"的大类：折线类（折线/阶梯/面积）、柱状类（纵/横/分组/堆叠）、散点类（散点/气泡）、分布类（直方/KDE/箱线/小提琴/stripplot）、热力类（热力/相关矩阵）、高级类（雷达/tornado/ROC/PR/QQ/收敛）。

### 多面板信息架构（三级递进）

- 每个面板独立可读：盖住任一面板，其余面板不留信息缺口。
- 推荐三级递进：面板 a 给概览/构成 → 面板 b 给偏离/异常（如 Z-score 热图）→ 面板 c 给关系/数学共变（散点/气泡）。
- 自检：面板 b 不是用不同图型重复面板 a 的数据；面板 c 增加了 a/b 不存在的维度；每个面板有独立轴标签词汇（不同 x/y 量）。
- 常见冗余陷阱：组成图配绝对图（应改配偏离图）、柱状+折线同数据、散点+折线同 x 轴。
