# 模型检验历次实测教训（按题型检索）

## 1. OOD 泛化与子集分层检验（XJTU 校赛 C）
- 若测试集含未见样本或未见特征对象，必须按四类子集分别报告：全 ID / 仅新样本 / 仅新特征对象 / 双新，并解释信息量差异导致的性能落差，不要只给单一平均分。

## 2. 瓶颈指派与调度逐点核验（2011 国赛 B）
- 瓶颈指派用「二分答案 + 二分图最大匹配」做第二实现路径交叉验证；调度类解必须逐节点验证硬截止时间不等式，不能只看总目标最优。

## 3. 优化/多目标四件套与退化一致性角（2023 国赛 D）
- **四件套脚本（增量落盘）**：
  1. `v1_deterministic_sensitivity.py`：全参数 Tornado（±5/10/20%）、不可行阶梯独立复算、对称性不变量测试、取整溢价分布；
  2. `v2_stochastic_robustness.py`：固定主输出，重抽种子×5 测噪声地板、分布**形状**扰动、分布**水平**移位（必须与形状扰动分开报）、外生系数、相关性与窗口长度；
  3. `v3_design_scan.py`：**退化一致性角**（把下游口径压回上游解析/LP 口径，验证数值逐项回落并写 `assert`）、范式一次性对照、业务杠杆扫描；
  4. `make_results.py`：非支配性、覆盖区间、HV 双实现与参考点、≥5 次重复均值±标准差、子集重算。
- **核心教训**：
  - 上界被超过就是真 bug（如闲置公羊栏不等式写反），修完必须全链重跑；
  - 水平移位与形状扰动分开报；小于蒙特卡洛噪声地板的波动不得声称“敏感”；
  - 区分“指标信息量”与“决策增益”（特征与代价相关 ≠ 改变最优动作）；
  - 粒度细化若做按模摊分，必须按模累加防止丢失规模；
  - 周期/稳态掩码必须声明有效域，越界格标注「超出有效域」；
  - 任何可行域/交付域口径变更后，必须 grep 全部下游规则与派生度量，防止“结论合规但动作违规”。
