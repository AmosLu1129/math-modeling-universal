# 数学建模规范知识库（选型 + 防错速查）

长期稳定的建模规范与防错知识。模型设计（`math-model-design`）、求解（`math-model-solver`）、写作（`math-paper-writing`）环节按需查阅。不要求为每条检查强行增加流程，具体产物以各环节技能为准。

## 五大题型识别

| 题型 | 核心问法 | 典型场景 |
|---|---|---|
| 优化类 | 求最大/最小，资源怎么分配 | 路径规划、调度、选址、装箱、投资组合 |
| 预测类 | 预测未来数值或趋势 | 销量/人口/价格预测、时序分析 |
| 评价类 | 对多方案综合排序或打分 | 城市评级、供应商选择、方案比选 |
| 分类/聚类类 | 判断对象属于哪类，或自动分群 | 风险识别、客户分群、图像识别 |
| 机理/动力学类 | 描述系统随时间的演化规律 | 传染病传播、生态系统、物理仿真 |

拿到题先问：输出是一个数（优化）、一条序列（预测）、一个排名（评价）、一个类别标签（分类）还是一组微分方程（机理）？混合题型按主问题定主模型，子问题按实际需求叠加。

## 选型决策树（快速版）

```
要预测未来数值？
  数据量 < 15 → GM(1,1) 灰色预测
  纯时序、无外部变量 → ARIMA / 指数平滑 / Prophet
  有多个影响因素 → 线性回归 / 岭回归 / 随机森林 / XGBoost
  非线性很强 → LSTM / GRU / XGBoost
  需要不确定性区间 → Bootstrap / MCMC

要评价/排序/选方案？
  需要体现专家经验 → AHP（主观赋权）
  完全客观数据驱动 → 熵权法（客观赋权）
  方案间距离排序 → TOPSIS / AHP+TOPSIS
  指标有模糊语言（好/中/差）→ 模糊综合评价
  评价效率（投入产出比）→ DEA
  数据少、信息不全 → 灰色关联分析
  指标多高度相关 → PCA + TOPSIS

要优化（求最大/最小）？
  目标和约束都是线性 → 线性规划 (LP)
  含整数/0-1 变量 → 整数规划 (IP/MIP)
  非线性目标或约束 → 非线性规划 / 遗传算法 / 模拟退火
  多目标冲突 → NSGA-II / 加权和法 / ε-约束法
  序贯决策 → 动态规划

要分类/分群？
  有标签（监督）→ 随机森林 / SVM / Logistic 回归 / 决策树
  无标签（无监督）→ K-means / 层次聚类 / DBSCAN
  文本/情感分析 → TF-IDF + LDA / BERT

要建机理模型？
  连续时间系统 → 常微分方程 ODE（SIR、Lotka-Volterra、Logistic 增长）
  偏微分/空间扩散 → PDE / 有限差分
  离散时间系统 → 差分方程 / 马尔可夫链
  不确定性/风险 → 蒙特卡洛模拟
  空间离散演化 → 元胞自动机
```

## 建模通用原则

- 假设必须必要、可解释、可参数化；每个关键假设说明理由、影响范围和替代解释。
- 物理约束和业务约束优先级高于拟合好看；计算方便不能成为删除关键机制的理由。
- 优化类：明确 min/max、决策变量类型与上下界、全部约束、可行解构造方法和求解算法适用规模。
- 多目标：先对各目标独立无量纲化，再加权或做 Pareto 分析；不能直接把成本、时间、风险等不同量纲指标相加。
- 预测类：防数据泄露——时序不能用未来信息训练；分类/回归要有训练验证划分或其他合理误差评估。
- 评价类：说明指标正负向、标准化方式、权重来源和敏感性检验；综合得分排序不能只给结果不解释机制。
- 动力学/仿真类：说明状态变量单位、初始条件、边界条件、求解器选择和步长/网格收敛性。
- 图论/路径/调度类：检查连通性、容量、时间窗、前驱关系、子回路、整数可行性和对称资源。
- 启发式算法不能直接宣称全局最优，除非有证明、精确求解对照或足够可信的稳定性验证。

## 评价类模型

### 选型原则

| 场景 | 推荐方法 |
|---|---|
| 有专家经验、需要层次结构 | AHP |
| 纯数据驱动、需要客观权重 | 熵权法 |
| 多方案综合排序 | TOPSIS（配合 AHP 或熵权） |
| 指标难以量化、存在模糊语言 | 模糊综合评价 |
| 数据少、信息不完整 | 灰色关联分析 |
| 评价效率（投入→产出） | DEA |
| 指标多、高度相关、需降维 | PCA + TOPSIS |
| 同时需要主客观权重 | AHP + 熵权组合权重 |

### 关键防错

- **AHP**：判断矩阵维度超过 9×9 时一致性极难保证，建议拆多级层次；一致性 CR < 0.1 才通过，不通过必须调整矩阵；权重归一化后求和为 1；最终得分 = 权重向量 × 方案矩阵，不是简单加法。
- **熵权法**：某指标所有方案取值相同时熵权为 0（无区分度）是正常结果，不是代码错误；标准化统一正负向，正向 `(x-min)/(max-min)`，负向 `(max-x)/(max-min)`。
- **TOPSIS**：必须有 2 个以上方案；欧氏距离对量纲敏感，必须先标准化；贴近度 C = D⁻/(D⁺+D⁻)，不是百分制得分；指标高度相关时先 PCA 降维。
- **模糊综合评价**：隶属度函数形状按问题语义选；合成算子通常选 M(·,+)（加权平均型），不要用 M(∧,∨)（主因素突出型）；指标维数过大时用二级模糊综合评价分层。

## 预测类模型

### 选型对照

| 模型 | 适用数据量 | 适用场景 | 主要限制 |
|---|---|---|---|
| GM(1,1) 灰色预测 | 4～15 点 | 短期、近似指数增长趋势 | 不适合长期或震荡数据 |
| 线性回归 | 30+ | 线性关系、需解释系数 | 无法捕捉非线性 |
| 岭/Lasso 回归 | 30+ | 多重共线性、高维特征选择 | Lasso 在强相关变量间不稳定 |
| ARIMA | 50+ | 平稳或可差分的单变量时序 | 不能直接处理多变量 |
| SARIMA | 50+ | 有季节性的时序 | 季节周期必须预先指定 |
| 指数平滑 | 10+ | 中短期、数据量少 | 长期趋势或复杂非线性差 |
| 随机森林 | 100+ | 非线性、多特征 | 外推能力弱 |
| XGBoost | 100+ | 非线性、需特征重要性 | 需调参，过拟合风险 |
| LSTM | 1000+ | 长序列复杂非线性 | 数据量少时不稳定 |

### 关键防错

- 时序必须按时间顺序划分训练/验证集，不能随机打乱；随机 K-Fold 不适用于时序，用 TimeSeriesSplit。
- 标准化 scaler 必须在训练集上 fit，再 transform 测试集；不能在全集上 fit。
- ARIMA 的 d 由 ADF 单位根检验确定，p、q 由 ACF/PACF 或 AIC/BIC 确定。
- 灰色预测只适合单调递增或近似指数增长序列。
- 预测结果检查物理边界（人口不能为负、概率不超过 1、库存不超上限）。
- 回归：VIF > 10 说明严重共线，用岭回归或删除高相关特征；残差应满足正态、方差齐、无自相关；外推超出训练范围时必须声明风险。

## 优化类模型

### 主要方法与适用规模

| 方法 | 适用规模 | 优点 | 缺点 |
|---|---|---|---|
| 线性规划 LP | 万级变量 | 全局最优，速度快 | 只支持线性 |
| 整数规划 MIP | 百~千级变量 | 处理整数/0-1 变量 | NP-hard，规模大时极慢 |
| 非线性规划 NLP | 百级变量 | 支持非线性约束 | 易陷局部最优 |
| 动态规划 DP | 状态空间小时 | 最优子结构精确解 | 维度灾难 |
| 遗传算法 GA | 任意规模 | 不需梯度，适合复杂约束 | 不保证全局最优，需调参 |
| 模拟退火 SA | 任意规模 | 逃出局部最优，实现简单 | 收敛慢，温度参数敏感 |
| 粒子群 PSO | 任意规模 | 连续空间效果好 | 离散变量需特殊处理 |
| NSGA-II | 多目标 | Pareto 前沿标准算法 | 目标数 > 3 时退化 |

### 关键防错

- 先写可行性约束，再考虑目标函数；没有可行解的模型比目标差的模型更致命。
- `scipy.optimize.minimize` 是最小化；最大化时目标取负，结果记录还原为正值。
- scipy 不等式约束形式是 `fun(x) >= 0`；容量上限 `x <= C` 写成 `C - x >= 0`。
- 整数约束：连续松弛后取整必须验证可行性；不可行用分支定界或修复启发式。
- 启发式（GA/SA/PSO）必须：固定随机种子、多次独立运行（≥5 次）、报告均值±标准差、与精确算法或小规模精确解对比。
- 维度较高的黑箱优化：先变量分组、几何/物理降维或分层优化；不要把十几个变量直接丢给 GA/PSO/DE 后接受结果。
- 组合优化：TSP/VRP 检查子回路（MTZ 约束或 lazy constraint）与容量/时间窗；指派问题每任务恰分一个资源、每资源至多一任务，矩形矩阵补虚拟行列；网络流检查流量守恒与容量约束，负权边用 Bellman-Ford。

## 机理/动力学类模型

### 常见微分方程模型

| 模型 | 核心方程 | 典型应用 |
|---|---|---|
| Logistic 增长 | dx/dt = rx(1 - x/K) | 种群增长、市场渗透、S 曲线预测 |
| SIR 传染病 | dS/dt、dI/dt、dR/dt 联立 | 疾病传播、谣言扩散 |
| SEIR 扩展 | 增加潜伏期 E 仓室 | 有潜伏期的传染病 |
| Lotka-Volterra | 捕食者-猎物联立方程 | 生态系统、市场竞争 |
| 牛顿运动方程 | ma = F | 力学、弹道、振动 |

### 关键防错

- 状态变量必须有物理/业务含义，量纲标注；初始条件（t=0）和边界条件必须明确。
- 刚性系统（时间尺度差异大）用 `solve_ivp(method='Radau'/'BDF')`，不要用默认 RK45。
- 检查守恒量：SIR 中 S+I+R=N；有耗散时能量单调递减。
- 数值步长收敛性：步长减半结果变化 < 1% 才算收敛。
- 参数拟合分离训练期和验证期，不能用全部数据拟合再同期验证。
- 蒙特卡洛：采样通常需 ≥10,000 次才稳定，报告置信区间不只报均值。
- 马尔可夫链：状态转移矩阵每行和为 1；稳态存在需不可约且非周期；区分吸收态与瞬态。
- 元胞自动机：网格边界条件（周期/固定/吸收）显著影响结果，必须说明理由。

## 图论与网络类模型

### 算法选型速查

| 问题类型 | 推荐算法 | 注意事项 |
|---|---|---|
| 单源最短路（非负权） | Dijkstra | 负权边不可用 |
| 单源最短路（含负权） | Bellman-Ford | O(VE) |
| 全对最短路 | Floyd-Warshall | O(V³)，适合稠密图 |
| 最小生成树 | Prim / Kruskal | Prim 稠密、Kruskal 稀疏 |
| 最大流 | Ford-Fulkerson / Dinic | 容量非负 |
| 最小费用最大流 | MCMF (SPFA+增广) | 兼顾流量与费用 |
| TSP（精确） | 分支定界 / DP | 超 20 节点计算量爆炸 |
| TSP（近似） | LKH / 遗传算法 | 无近似比保证 |
| 二分图最大匹配 | 匈牙利算法 | 指派问题标准解法 |

### 关键防错

- 明确有向/无向；有向图入度与出度是不同概念。
- 无向边转最大流时化为两条反向、容量相同的有向边。
- TSP 必须检查 Hamiltonian 回路约束，禁止子回路；中间节点流量守恒（流入=流出）。
- 节点数 > 1000 时 Floyd 的 O(V³) 不可接受，改用多次 Dijkstra。

## 统计分析与机器学习

### 统计检验速查

| 目的 | 推荐方法 | 适用条件 |
|---|---|---|
| 两组均值差异 | t 检验 | 正态、方差齐 |
| 多组均值差异 | 单因素 ANOVA | 正态、方差齐 |
| 非参数两组比较 | Mann-Whitney U | 不要求正态 |
| 变量相关性 | Pearson（线性）/ Spearman（非线性） | Pearson 要求正态 |
| 分类变量独立性 | 卡方检验 | 期望频数 ≥ 5 |
| 时序平稳性 | ADF 单位根检验 | — |
| 正态性检验 | Shapiro-Wilk（小样本）/ K-S | — |

### 机器学习防错

- 过拟合防护：训练/验证/测试三分；验证集用于调参，测试集只评估最终模型。
- 类别不平衡：Accuracy 失效，改用 F1、AUC-ROC 或 Precision-Recall。
- 特征工程（标准化、One-Hot 等）必须在划分后、在训练集上 fit。
- 特征重要性：SHAP 比 `feature_importances_` 更可靠（后者对相关特征有偏）。

## 论文写作要点（与竞赛规则配合使用）

- 论文不是工作日志：正文不出现内部文件名、脚本名、临时目录、工作流说明或"由 AI 生成"等过程痕迹。
- 摘要/Summary Sheet 覆盖每个子问题的方法与关键结果，数值必须与结果记录一致；中国赛摘要 ≤2 页，不翻译英文；美赛 Summary Sheet 独立一页，突出方法亮点与关键结论。
- 公式出现后解释符号含义；图表出现前后要有引导和解释，不能连续堆图。
- 章节结构跟随赛题类型和模板：三问建模题按问题展开；统计建模可按研究逻辑链组织，不必硬凑"问题一二三"。
- 参考文献必须真实存在，没把握的文献不写入。

### 灵敏度分析规范

- 灵敏度分析不是可选项，是竞赛论文的必要内容。
- 单参数扰动（±10%、±20%）观察目标变化，或 Tornado 图展示参数影响力排序。
- 优化类：改变约束右端项或目标系数，观察最优解是否质变。
- 预测类：改变关键假设或初始条件，观察预测曲线漂移幅度。
- 若小扰动导致结果大幅变化，说明模型对该参数敏感，须在论文中声明。

### 常见写作错误（防错清单）

- 假设没在正文建模处引用 → 形同虚设。
- 结论只给数值不解释含义 → 说明对应什么方案、什么业务含义。
- 图表出现但正文没有引导和解释；连续三张以上图表中间没有文字。
- 公式符号首次出现处没定义。
- 参考文献捏造或无法核实。
- 摘要与正文数值不一致 → 摘要最后写、从正文复制数值。

## 题型规律与高频组合（MCM/ICM 参考）

- A 题（连续型）：PDE、物理/工程建模、优化；推导要求高。
- B 题（离散型）：图论、调度、组合优化、排队论；算法实现要求高。
- C 题（数据洞察型）：数据分析、机器学习、时序预测、可视化。
- D/E/F 题（ICM）：运筹、可持续性、政策分析；跨学科与文字论证要求高。

| 问题类型 | 推荐组合 |
|---|---|
| 综合评价 | AHP + TOPSIS 或 AHP + 熵权 + TOPSIS |
| 预测 + 不确定性 | XGBoost/随机森林 + Bootstrap 置信区间 |
| 风险评估 | Logistic 回归 + 蒙特卡洛模拟 |
| 时空预测 | ARIMA/LSTM + 空间聚类 |
| 投资/资源优化 | 预测模型 + 动态规划/遗传算法 |
| 状态建模 | 马尔可夫链/HMM + 随机森林验证 |
| 文本分析（C 题） | TF-IDF + LDA 主题模型 + 情感分析 |
