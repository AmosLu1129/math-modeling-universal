# 数据预处理与探索性分析

## 输入输出

- 输入：`input/data/*`（`.mat` / `.csv` / `.xls` / `.xlsx`），配合 `work/brief.md` 的变量说明
- 输出：`work/data_clean/*.csv`、`work/data_dictionary.md`、`work/eda_report.md`

## 无附件纯优化题（`input/data/` 为空，2026-09-03 实测：2023 国赛 D）

赛题把全部给定数字写在题面文字里（周期天数、每栏容量、单价、比例参数）时，本环节**不能跳过**，退化为「给定量字典 + 口径归一 + 量级预检」三件套：

1. **给定量入表**：`work/data_clean/given_params.csv`，列 `param_id,symbol,name_zh,value,unit,dtype,scope,source,kind,note`；`scope` 标每条参数被哪几个小问使用，`kind` ∈ const/decision/random/derived/check。题面每一个数字都要有一行，缺行即视为漏读题。
2. **求解器只认这张表**：环节 5 代码禁止硬编码题面数字（`M=20` 这类字面量只允许出现在读取失败时报错）。这是 2011B「坐标单位未写」教训的正向版本——把口径集中到一处才好复核与改单位。
3. **可控参数要识别出来**：题面写"可调控/经验做法"的量（如哺乳期 35–45 天、休整期 ≥18 天、"每 ±1 天 → ∓2 天"的折算）标 `kind=decision`，它们是后续小问的决策变量而非参数，别在数据环节当成常数固化。
4. **口径归一表**：题面同一物理量常有"约 3 周"与"20 天"两种写法，`data_dictionary.md` 必须列表说明**采用哪一个 + 理由**，并声明全文统一的出栏/年化/损失单位口径（栏·天）。
5. **`eda_report.md` 改为量级预检**（没有数据可画图）：① **题面自算例/自等式复算**（如"42 只母羊→3/6/7/9 栏"、"229 天周期→2 年 3 胎"）作为口径锚点，逐条 ✅/❌；② 稳态/闭式系数估算瓶颈（哪一阶段占资源最多）；③ 给出后续小问答案的**预期带**（上下界 + 文献可执行方案作下界）；④ 离散化取整偏差量化（如把 149 天四舍五入到整周会让年化产出系统性偏 -3.78%）；⑤ 多目标冲突的结构性证据（目标对决策变量是否单调同向）——这一条直接决定范式选择，是 `model-first-sop.md` §3 的输入。

## 读取

- `.csv`：pandas 读取；自动探测编码（utf-8/gbk）与分隔符；列名清洗。
- `.mat`：
  - 优先 `scipy.io.loadmat`（v5 格式）。
  - v7.3（HDF5）用 `h5py` 读取；检查文件头是否含 `MATLAB 7.3` 字样判断。
  - struct/cell 逐层展平为 DataFrame；保留原始变量名映射（如 `X_train`、`data(:,1)`）。
- `.xls/.xlsx`（pandas `read_excel`，openpyxl 引擎，`setup_env.py` 已含）：
  - **先盘点 sheet**：逐 sheet 读取并记录 sheet 名与角色——数据表 / 元数据（metadata）表 / 说明表 / 结果模板；元数据表的变量说明、单位、分组信息必须并入数据字典，不能丢弃。
  - **表头不一定在第 0 行**：可能含标题行、注释行、合并单元格；先读全表判断表头行位置再设 `header`，列名清洗同 `.csv`。
  - 关键列用 `dtype=str` 读防精度丢失（长 ID、编码列），数值列再 `astype`；日期统一格式；文本数字混排按列处理。
- **统一中间格式**：所有数据转成整洁 csv + `data_dictionary.md`（变量、单位、含义、来源、处理记录），后续环节只认这一种格式。

## 清洗手册

- 缺失值：记录比例与位置；数值型按场景选插值/均值/模型填补/删除，分类型用众数；策略写入数据字典。
- 异常值：3σ / IQR / 业务合理性三重判断；区分"真异常"与"有效极值"，不能一刀切删除。
- 重复值与格式不一致：去重、统一日期/单位/类别名。
- 标准化/归一化：需要时保存 scaler 参数，论文回代原始单位时可用。

## EDA 必出内容

- 变量字典（含缺失与异常处理记录）
- 分布（直方图/箱线图）、相关性（热力图）、时间趋势、类别分布
- 关键发现列表：每条都要能支撑建模决策（如"特征 A 与目标强相关""存在强共线性"）

## 划分

- 需要训练/测试划分时固定 random_state 并保存划分索引；时间序列按时间切分，不随机洗牌。

## 无附件/开放赛题「真实世界实证锚点」收集（`o_award` 必填 / 通用推荐）

当赛题不提供实测数据附件（如 MCM A 类机理建模或开放策略题）时，**严禁只用抽象合成情景（如 `S1..S7`）自娱自乐**：
1. **引入 1–2 个具象可查证真实基准对象**：整理存入 `work/data_clean/benchmarks/`（例如具体型号手机公开电池/温升实测曲线、具体历史石阶材质与公开磨损参数、公开标准对照样本），明确标注真实来源与单位换算，并在后续阶段 6 做端到端拟合残差校对。若需要人工实拍/专有实测数据，按 `workflow-contract.md` 第 8 节开具标准协助工单。
2. **Before-vs-After 清洗对比留痕（按需）**：若异常值剔除、口径统一或重采样带来了分布/相关性结构的显著改变，在 `eda_report.md` 与 `data_clean/` 保留清洗前后汇总数组，供阶段 7 绘制直观的视觉对比图。


## 实测教训（2026-08-10，XJTU 校赛 C：1140 细胞系 × 1123 基因 × 87 万样本对）

- 千万级行 × 千列的**全宽表 merge（把细胞系特征横向铺到每个样本对上）内存会卡死**（本机 8GB 级内存实测失败）。改用「紧凑表」方案：细胞系特征表、基因特征表各自单独存 csv/npy，样本对只存键（cell_line_id, perturbation_gene），需要拼接特征时用**索引映射**（dict: id→行号）按需构建，float32 存储。
- 大矩阵特征工程统一 float32；PCA 降维放在 merge 之前做（先降维再拼接，避免高维中间矩阵）。

## 质量要求

- 每个清洗结果可回溯：原始文件 → 处理脚本 → 清洗结果。
- `.mat` 与 Excel 中的原始变量名、sheet/列名、单位、维度信息进入数据字典，供论文符号说明复用。

## 结果模板回填（纯模板型题目）

- 当附件是“结果模板 xlsx”（无观测数据）时，数据环节退化为：**解析模板结构 → 求解后按列名+行语义回填**。
  - **零配额口径（2026-08-12，2024 国赛 C）**：预期销售量按"基年产量"汇总时，基年未种但兼容表允许的作物要**显式补 0 配额**，否则模型会无限量售卖该作物、产生虚假上界（修正后 Q1.1 从 5113 万回落到 4125.9 万）；清洗脚本中**所有"按行索引取值"必须改为按列名断言取值**（曾把 row[5] 产量当季次用，导致口径错位）。
- 教训（2026-08-09 实测，2025 国赛 A）：模板可能含注释行（如“注：以 x 轴为正向……”）与固定行数，直接按行号回填会错位。必须先读全表，识别 表头行 / 数据行 / 注释行，按「表头列名 → 求解结果字段」映射回填，且**保留注释行原样**；回填后用 openpyxl 读回逐行核验（行数、列数、关键数值）。

## 实测教训（2026-08-16，2011 国赛 B）

- **题面/附件不写坐标单位时不要默认米**：先翻本地优秀论文交叉证实口径（本题坐标单位为百米，3 分钟=30 单位；错当成米会把覆盖率等所有距离类结论算崩 10 倍）。数据字典必须写明“单位与换算口径”。
- 读 .xls 需要 `xlrd`（pandas 默认不装）；setup_env.py 的 pip 检查曾漏掉 xlrd → 已回写 setup_env.py 增查。
